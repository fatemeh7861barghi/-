# -🏢 موضوع ۳۳: سامانه مدیریت شارژ ساختمان
۱. معرفی پروژه
این سامانه برای مدیریت هزینه‌های مشترک یک ساختمان طراحی می‌شه. مدیر ساختمان می‌تونه هزینه‌ها رو ثبت کنه، سهم هر واحد رو محاسبه کنه و وضعیت پرداخت شارژ ساکنان رو بررسی کنه.
۲. چه مشکلی رو حل می‌کنه؟
در خیلی از ساختمان‌ها، شارژها و هزینه‌ها با دفتر یا فایل‌های پراکنده ثبت می‌شن. این موضوع ممکنه باعث اشتباه در محاسبات، فراموش‌شدن پرداخت‌ها و نامشخص‌بودن هزینه‌های ساختمان بشه.
این برنامه اطلاعات رو منظم می‌کنه و محاسبات رو ساده‌تر می‌کنه.
۳. ویژگی‌های اصلی برنامه
ثبت اطلاعات واحدها و ساکنان
تعیین مبلغ شارژ ماهانه هر واحد
ثبت هزینه‌های ساختمان مثل نظافت، آسانسور و تعمیرات
محاسبه سهم هر واحد از هزینه‌ها
ثبت پرداخت‌های ساکنان
